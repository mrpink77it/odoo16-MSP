# odoo18-MSP
Managed Service Provider

# Introduzione
Presentazione del progetto MSP e scopi principali.

# Configurazione dell'Infrastruttura
- Installazione di Odoo 18 su Proxmox VE.
- Panoramica della configurazione dell'infrastruttura.

# Modelli Personalizzati
- Creazione di modelli personalizzati come res.partner e fleet.vehicle.
- Utilizzo di smart button per accedere alla scheda veicolo di proprietà.

# Integrazione API
- Integrazione con Teltonika FOTA WEB per provisioning automatico.
- Integrazione con Emnify / Geotab per gestione dello stato delle SIM.
- Integrazione con Traccar Server per recupero di log di viaggio.

# Orchestrazione DevOps
- Gestione del clustering e failover con Proxmox VE.
- Uso di script Bash per configurare il server e gestire le risorse.

# Automazioni
- Automazioni per reindirizzamento IP via FOTA.
- Implementazione di script di backup e failover DNS.
- Motore di billing automatizzato per la fatturazione mensile.
